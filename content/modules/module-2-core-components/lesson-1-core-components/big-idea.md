Agents are not black boxes. They are modular systems built from three distinct, configurable components: **The Model** (which interprets inputs and reasons through decisions), **The Tools** (which let the agent interact with external systems), and **The Instructions** (which guide behavior, tone, and priorities).

> **In Plain English:** Think of the agent as an explorer: the Model is the Brain, Tools are the Hands and Feet, and Instructions are the Compass and Code of Conduct.
