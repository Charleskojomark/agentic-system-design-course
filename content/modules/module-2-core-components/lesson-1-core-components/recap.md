# Lesson 2 Recap: Key Takeaways

- **The Three Pillars:** Every agent is composed of the **Model** (thinking and planning), **Tools** (acting in external systems), and **Instructions** (guiding tone, constraints, and priorities).
- **Thoughtful Model Selection:** Match your LLM to the task requirements: balance task complexity, inference latency, cost-per-token, and context length rather than simply defaulting to the biggest model.
- **Modularity is Essential for Production:** Decoupling models, tools, and instructions ensures you can swap LLMs, extend API tools, and isolate bugs without rebuilding your entire system.
