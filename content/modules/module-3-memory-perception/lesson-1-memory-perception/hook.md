# A returning user says: "Book the same hotel as last time."

What if your agent has no memory?

It stares back blankly and asks: *"Which hotel did you mean? What city was it in? What dates?"*

The user is instantly frustrated. Every interaction feels like starting over from scratch. 

To behave intelligently across time and multi-turn workflows, an agent must perceive dynamic environmental signals and remember what has happened across sessions.
