# Lesson 3 Recap: Key Takeaways

- **The Continuous 5-Step Loop:** Agents do not merely react once; they operate through **Perceive → Recall → Reason → Act → Store**, constantly learning from the consequences of their actions.
- **Environmental Sensing:** Perception translates multimodal streams (speech, screenshots, JSON payloads, sensor telemetry) into structured context ready for LLM reasoning.
- **Three Tiers of Memory:** Coherent systems combine fleeting **Short-Term Memory** (session context buffers), persistent **Long-Term Memory** (user history and profiles), and scalable **External Knowledge** (Vector databases with RAG).
