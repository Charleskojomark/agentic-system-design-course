# Lesson 1 Recap: Key Takeaways

- **Perceive-Reason-Act Loop:** Unlike passive models that compute outputs and halt, an AI agent operates continuously in a cycle of sensing its environment, reasoning toward goals, and executing real-world actions.
- **Three Operational Categories:** Agents exist as purely digital software systems (APIs, chatbots), physical embodied robots (sensors and actuators), or hybrid adaptive systems (traffic systems, smart logistics).
- **Be Strategic About Agentic Design:** Only build an LLM agent when the task genuinely requires contextual judgment, handles unstructured language, or possesses rules too complex for deterministic maintenance.
